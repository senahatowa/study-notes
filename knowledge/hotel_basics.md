# 🏨 ホテル基礎ノート

👉 **[ど素人ホテル（@4610\_hotel）のナレッジはこちら](doshiroto.html)**

ホテルSNSを**ど素人から**始めるための前提知識。**種類・格・ブランド・部屋・料金・館内用語・会員・SNSのルール**をこのページ1枚にまとめた。各章の頭にある**「ここだけ」**から読めばOK。

## 0まず全体像 — ホテルは「3つの軸」で見る

どのホテルも、この3つで説明すれば素人っぽくならない。

① どんな種類？

ビジネス／シティ／ラグジュアリー／リゾート／旅館／ライフスタイル…**「誰が・何のために泊まる場所か」**。

② どの格？

価格帯・部屋の広さ・ブランドの階層で**「どのランクか」**。同じグループでもブランドで格が全然違う。

③ 何が売り？

眺望・朝食・ラウンジ・プール/サウナ・デザイン・アクセス。**投稿の切り口になるのはここ**。

**ここだけ：**投稿の一文目は「**〇〇（エリア）の△△（種類・格）で、□□が売り**」で言える状態を目指す。例：「虎ノ門の外資ラグジュアリーで、夜景のプールが売り」。

## 1ホテルの種類

呼び方は業界で揺れるけど、SNSで通じる分け方はこれ。

ビジネスホテル 1〜2万円目安

出張客向けで、泊まるだけに特化している。部屋は**12〜18㎡**くらい。例：東横イン、アパ、ドーミーイン（大浴場が強み）、三井ガーデン。

シティホテル

宿泊に加えて**宴会・婚礼・レストラン**を持つ大型ホテル。例：帝国ホテル、ホテルオークラ、ニューオータニ、プリンス系。

ラグジュアリーホテル SNS映え◎

サービス・内装・広さが最上級（**40㎡〜**）。外資系ブランドが多い。高層階のロビーと眺望が定番。

リゾートホテル

観光地にあって、**滞在そのものが目的**。プール・スパ・アクティビティが揃う。沖縄・軽井沢・箱根など。

旅館 日本独自

和室・温泉・**1泊2食（夕朝食付き）**が基本。料金は**1人あたり**の表示が多い。高級旅館＝「ラグジュアリー旅館」。

ライフスタイル／ブティック

デザイン・カルチャー・地域性が売りの、小〜中規模ホテル。若い層に刺さる。例：ACE系、KIMPTON、各地のデザイナーズホテル。

オーベルジュ

**レストランが主役**の宿。「食べに行って泊まる」ための場所。

一棟貸し・ヴィラ／グランピング

建物ごと、またはテントごと貸切にする形。家族やグループ向けで、プライベート感が売り。

カプセル／ホステル

相部屋や簡易な個室の格安宿。最近は「おしゃれカプセル」も多い。

**豆知識：**法律（旅館業法）上は、ホテルと旅館は2018年から**「旅館・ホテル営業」**としてまとめて扱われている。カプセルやホステルは「簡易宿所」、民泊は別の法律（住宅宿泊事業法）の対象。

## 2格（ランク）の見分け方

ホテルに星の公式な国内基準はない。だから下の4つから総合で判断する。

| 格 | 東京の1泊目安※ | 広さ目安 | 代表例 |
| --- | --- | --- | --- |
| ウルトラ ラグジュアリー | 20万円〜 | 60㎡〜 | アマン東京、ブルガリ ホテル 東京、ジャヌ東京 |
| ラグジュアリー | 8〜20万円 | 45〜60㎡ | リッツ・カールトン東京、フォーシーズンズ、マンダリン オリエンタル、ペニンシュラ、パレスホテル東京 |
| アッパー アップスケール | 4〜8万円 | 30〜45㎡ | ウェスティン、コンラッド、インターコンチネンタル、グランドハイアット |
| アップスケール | 2〜4万円 | 20〜30㎡ | コートヤード、ハイアット セントリック、ホテルインディゴ |
| ミッド〜エコノミー | 〜2万円 | 〜20㎡ | ビジネスホテル各社、ibis など |

※1室あたりの税込目安。時期・曜日・為替で大きく動く（特に近年は高騰中）。**投稿する前に必ず実際の価格を確認すること。**

### ランクを判断する4つの材料

- **価格**：一番わかりやすい。同じホテルの**平日と週末の差**も見ておく。
- **最小の部屋の広さ（㎡）**：「一番安い部屋で何㎡か」を見ると格がわかる。
- **ブランド階層**：同じマリオット系でも、リッツ・カールトンとモクシーは別物（→ [3章](#brands)）。
- **外部の評価**：**Forbes Travel Guide**（星）、**ミシュランキー**（ホテル版ミシュラン、2024年開始）、**The World's 50 Best Hotels**（2023年開始）など。

### 知らないと恥ずかしい「御三家」

ホテル御三家（老舗の日系）

**帝国ホテル**・**ホテルオークラ（The Okura Tokyo）**・**ホテルニューオータニ**。日本のホテル史の基準になっている。

新御三家（90年代の外資系）

**パーク ハイアット 東京**・**ウェスティンホテル東京**・**椿山荘**（旧フォーシーズンズ椿山荘、現ホテル椿山荘東京）。

**トレンド：**東京は2020年代に**外資ラグジュアリーの開業ラッシュ**が起きた（虎ノ門・麻布台・銀座・大手町など）。**「新規開業」と「リニューアル」**はSNSで伸びやすい鉄板ネタ。

### その他、よく出る言葉

- **〇〇ビュー**：シティ／オーシャン／タワー（東京タワー・スカイツリー）／パーシャル（窓から一部だけ見える）。
- **コーナールーム**：角部屋。窓が2面あって人気。
- **コネクティング**：中のドアで隣の部屋とつながる部屋。家族向け。
- **ビューバス**：景色が見えるバスタブ。SNSで強い。
- **和洋室**：ベッドと畳スペースがある部屋。旅館やリゾートに多い。

## 5料金と予約の仕組み

料金の単位

ホテルは**1室あたり**が多く、旅館は**1人あたり**が多い。投稿では**「2名1室・税込〇円」**まで書くと親切。

食事条件

**素泊まり**（食事なし）／**朝食付き**／**1泊2食**（夕朝食付き）。同じ部屋でもプランで値段が変わる。

追加でかかるもの

**サービス料**（高級ホテルは13〜15%前後のことも）、**消費税**、**宿泊税**（東京・京都・大阪など。→ [11章](#news)）、**入湯税**（温泉地）。「表示価格に何が含まれるか」は要チェック。

値段が動く理由

**ダイナミックプライシング**で、需要（曜日・連休・イベント）に応じて毎日値段が変わる。「〇万円で泊まれた」は**日付込み**で書く。

### 予約先は2種類

| 予約先 | 特徴 |
| --- | --- |
| 公式サイト | 会員特典（ポイント・アップグレード等）が付く。**ベストレート保証**（他サイトより安ければ差額保証）があることも |
| OTA（予約サイト） | 国内：**一休**（高級に強い）・**楽天トラベル**・**じゃらん**・**Relux**。海外系：**Booking.com**・**Expedia**・**Agoda**。ポイントやセールが強い |

**ここだけ：****返金不可プラン**は安いけど、キャンセルしても返金されない。「同じ部屋が**どこで一番安いか**」を比べた結果は、それだけで保存される投稿になる。

## 6館内の施設・サービス用語

クラブラウンジ

上位の部屋や会員だけが使える専用ラウンジ。**朝食・ティータイム・カクテルタイム**（夕方の軽食とお酒）がある。**SNSで一番伸びるネタの一つ**。

コンシェルジュ

レストランの予約や観光の手配をしてくれる係。

ターンダウン

夕方に部屋を寝る準備の状態に整えてくれるサービス。小さなギフトが置かれていることも。

アメニティ

シャンプーなどの備品。**どこのブランドか**（ル・ラボ、ディプティック、バイレード等）は話題になる。

アーリーIN／レイトOUT

通常より早くチェックインする／遅くチェックアウトする。有料のこともあれば、会員特典で無料になることも。

アップグレード

予約したより上の部屋に無料で変えてもらえること。会員ステータスや空室状況で決まる。

インルームダイニング

ルームサービスのこと。

ミニバー

部屋の冷蔵庫の飲み物。**無料（コンプリメンタリー）か有料か**は要確認。

デイユース

宿泊せず、日中だけ部屋を使うプラン。

アフタヌーンティー

ホテルラウンジの定番。**季節ごとにテーマが変わる**ので、毎シーズン投稿できるネタになる。

スパ／ウェルネス

プール・ジム・サウナ・トリートメント。**宿泊者なら無料か有料か**は必ず書く。

バトラー

スイートなどに付く専属スタッフ。

## 7会員プログラムと上級会員

ホテル好きの層は「ステータス」の話が大好き。ここがわかると、その層と会話ができる。

| グループ | ランク（下→上） |
| --- | --- |
| Marriott Bonvoy | メンバー → シルバー → ゴールド → プラチナ → チタン → アンバサダー |
| Hilton Honors | メンバー → シルバー → ゴールド → ダイヤモンド |
| World of Hyatt | メンバー → ディスカバリスト → エクスプローリスト → グローバリスト |
| IHG One Rewards | クラブ → シルバー → ゴールド → プラチナ → ダイヤモンド |
| Accor ALL | クラシック → シルバー → ゴールド → プラチナ → ダイヤモンド |

- **上級会員の主な特典**：部屋のアップグレード、ラウンジの利用、朝食無料、レイトチェックアウト、ポイントの上乗せ（ランクによって違う）。
- **修行**：ステータスを取るために泊まりまくること。**ホテル系クレジットカード**を持つだけで中級ステータスが付く場合もある。
- **ポイント泊**：ポイントを使って無料で泊まること。「〇ポイントで泊まれる高級ホテル」は人気ネタ。

**注意：**ランクを取る条件や特典は**毎年のように変わる**。数字を投稿するときは、必ずその時点の公式情報を確認すること。

## 8SNS運用のための知識

### 見る人が知りたいこと TOP10（投稿に入れる順）

1. **いくら？**：日付・人数・税込・プラン名
2. **どこ？**：最寄り駅と徒歩何分か
3. **誰向け？**：カップル／一人／子連れ／記念日
4. **部屋**：タイプ名・㎡・ベッド・眺望
5. **朝食**：ビュッフェかセットか、名物
6. **風呂**：ビューバス・大浴場・サウナ
7. **プール・ラウンジ**：使える条件と時間
8. **アメニティ**：ブランドと持ち帰れるか
9. **予約のコツ**：どこで予約すると安いか・得か
10. **正直なマイナス点**：あると信頼される

### 伸びやすい切り口

価格フック

「〇万円台で泊まれる外資系」「1人1万円以下の〇〇」など。

新規開業・リニューアル

開業直後は検索されやすい。「開業1か月で行ってきた」など。

比較・まとめ

「東京のホテルプールBEST5」「エリア別」などは**保存されやすい**。

季節ネタ

アフタヌーンティー、桜・紅葉・夜景、クリスマスケーキ。

体験ルート

「チェックインからチェックアウトまで」を時系列で見せる。リールと相性が良い。

知識ネタ

このページの内容そのもの（ツインとダブルの違い、ラウンジとは、など）。

### 守るべきルール

**ステマ規制（2023年10月〜、景品表示法）：**招待・無料宿泊・報酬がある投稿は、**「PR」「広告」「提供：〇〇」**などとわかるように書く。書かないと規制の対象になる。

- **他の宿泊客やスタッフの顔**を許可なく写さない。
- **大浴場・スパ・更衣室**は基本撮影NG。ロビーやレストランでも撮影ルールがあることが多い。
- **部屋番号・カードキー**を写さない。**リアルタイム投稿**は居場所がバレるので、チェックアウト後に投稿するのが安全。
- **他人の写真や公式写真を無断転載**しない。

## 13運用・収益化（2026年11月調べ）

Webで調べた内容。数字や仕様はすぐ変わるので、要確認の付いたものは公式で確かめてから使う。

### Instagramのアルゴリズム（公式に近い情報）

- **重視される3つの指標**（Instagram責任者モッセーリ氏、2025年1月）：**視聴時間**、**リーチあたりのいいね**、**リーチあたりの送信（シェア）**。フォロワー以外に届けるには**「誰かに送りたくなる」**投稿が強い。
- **リールの長さ**：2025年1月から**最長3分**に延びた（それまでは90秒）。
- **トライアルリール**：2024年12月に始まった機能。**フォロワー以外に先に見せて**反応を試せる。
- **オリジナル優遇**：他人の投稿の転載よりも、**自分で撮った投稿**が優遇される（2024年4月発表。2026年には写真やカルーセルにも広がったと報道されている）。
- **ハッシュタグは1投稿5個まで**（2025年12月〜、以前は30個）。その分、**キャプションに地名・ホテル名・「ホテルプール」などの検索語を書く**ことが大事になった。
- **投稿頻度**：公式の正解はない（モッセーリ氏いわく「完璧な数字はない」）。**続けられる頻度で、毎回の質を上げる**のが基本。

**ここだけ：**「**保存されるか**（あとで見返したい情報があるか）」と「**送られるか**（『ここ行こう』と友達に送りたくなるか）」の2つを、毎回の投稿で狙う。

### TikTok

推薦は**最後まで見られたか・いいね・シェア・スキップ・フォロー**などで決まる（各要素の重みは非公開）。収益化の**Creator Rewards Program**は日本でも使えて、対象は**1分以上の動画**。条件は「フォロワー1万人以上・18歳以上・直近30日で10万回再生以上」と紹介されることが多い 要確認

### お金になる道

① 予約サイトのアフィリエイト

投稿からのリンク経由で予約が入ると、宿泊料金の数%がもらえる。報酬率の目安：**一休 1%・Relux 2%・じゃらん 1%・楽天トラベル 1〜2%**。海外系（Agoda・Booking.com）はもっと高いという情報もある。

ASP（アフィリエイトの仲介サービス）は**バリューコマース・A8.net・もしもアフィリエイト・楽天アフィリエイト**など。要確認報酬率は各ASPの管理画面で確認する

② ホテルからの招待・PR案件

まずは**報酬なしの招待宿泊**から始まるのが普通。報酬の相場は「1フォロワーあたり2〜4円」という記事もあるけど、**フォロワー数よりも保存・予約につながるかで評価される**ようになってきている（同じフォロワー数でも、PR効果に50倍以上の差があったという調査もある）。

③ ホテル側からの紹介料

ホテル紹介アカウント「Check in」は、**59投稿でフォロワー5.9万人**を獲得した事例として分析されている（SAKIYOMI調べ）。支持された理由は「**広告っぽくない**」こと。

④ 公式の収益化機能

Instagramの**サブスクリプション**（2023年7月から日本でも使える）、**ギフト**（2023年11月〜）、TikTokの**Creator Rewards**など。最初の柱にはならないので、おまけと考える。

⑤ Agodaのアンバサダー制度

2025年10月に発表されたクリエイター向けの制度。**専用のプロモコード**を使って予約されると報酬が入る。

### リンクの置き場所

- **ストーリーズのリンクスタンプ**：フォロワー数に関係なく使える。ただし作ったばかりのアカウントでは使えない場合がある。
- **プロフィールのリンク**：複数置ける。**「このホテルの予約リンクはプロフィールから」**という導線が定番。

### PR表記のルール（ステマ規制）

**ステマ規制（2023年10月施行）：**規制の対象は**依頼した側（ホテル）**。ただし表記を忘れると、ホテルに迷惑がかかって**次から案件が来なくなる**。**無料の招待宿泊も「対価」にあたる**。

- **表記の例**：「PR」「広告」「プロモーション」「〇〇ホテルから宿泊の提供を受けて投稿しています」。
- **表記の位置**：キャプションの**冒頭など目立つ場所**に書く。ハッシュタグの中に紛れ込ませるのはNG。
- Instagramの**ブランドコンテンツタグ（タイアップ投稿ラベル）**と、文字での表記を**両方使う**のが安全。
- 他人の顔が写った写真は**肖像権**の問題になり得る。**ホテルの公式写真は著作物**なので、使うなら許可を取る。ホテルごとの撮影ルールも確認する（例：ホテルオークラの投稿規約には「特定の人物が写っていないこと」という条件がある）。

### 🏝 ど素人ホテル再建計画（@4610\_hotel）

**どんなアカウントか**：運営は**片岡力也さん**。ホテル経営の経験ゼロで、2022年に沖縄・恩納村の**赤字ホテル「なかどまINN」（16室、今のBUZZ RESORT）**の再建を任され、その過程を発信している。**ホテルを紹介するアカウントではなく、再建そのものを見せるドキュメンタリー型**。今は「バズ塾」を主宰して、他社のSNS設計も手がけている。

**規模（本人の申告）**：YouTube 15万人、TikTok 13万人、Instagram 約6万人。「始めて2週間で2万フォロワー」。

① 最初の2秒で決まる

インタビューの見出しは「**バズる動画は、最初の2秒で決まる**」。最初の2秒で9割以上の人が離脱する、という趣旨の発言がある。

② 強い言葉を組み合わせる

### 🧱 カルーセル投稿の型

1. **表紙**：2枚目以降まで見てくれる人は**平均35〜45%**だけ。だから表紙は「タイトル＋続きを見る理由」に絞って、大事な言葉を大きくする。
2. **中身**：**到着から翌朝までを時系列**で並べる。または、外観・部屋・食事・風呂・アクセスを1投稿にまとめる。
3. **まとめ**：価格（1泊〇円〜）、場所、こんな人におすすめ。
4. **最後の1枚**：「保存して次の旅行の参考に」「予約はプロフィールのリンクから」。

枚数は**7〜10枚**がいいとする記事がある（根拠ははっきりしない）。キャプションは**最初の2行**で続きを読む理由を書く。

### ⚡ リールとTikTokの型

- **15〜30秒**で、「冒頭のフック → 体験（部屋に入った瞬間の景色など） → 余韻（朝の景色）＋行動の呼びかけ」の順にする。
- **結論から見せる**：一番魅力的なシーン（絶景・料理のアップ・ドアを開ける瞬間）を冒頭に置く。
- 字幕は**1文7〜10文字以内**。宣伝っぽさより**共感とリアルさ**で伸びる。
- 冒頭に**問いかけ**の字幕を入れたら、最後まで見られる率が上がった事例がある。

### 🪝 冒頭のフック例（記事に載っていたもの）

- 「知らないと損する、絶景が見えるホテル」
- 「え、そんなホテルあるの？」
- 「ディズニーに行くなら絶対に知っておくべき、約6000円から泊まれるホテル」
- 「博多駅から徒歩圏内！コスパ最強の神ホテル」
- 「全室オーシャンビューの朝」／「朝食で人気のメニュー3選」

**ここだけ：**型は**「最初の2秒」**×**「誰向けかを絞る」**×**「保存したくなる情報（価格・予約のコツ）」**。紹介垢でいくなら Check in のように**広告っぽくしない**。ど素人ホテルのように**自分の物語**で見せる道もある。

## 16撮影のコツと旅館・温泉の基礎

スマホだけで撮る前提。旅館・温泉は間違えると恥ずかしい知識が多いので、ここで押さえておく。

### 📸 部屋の撮り方

- **チェックインしたら、荷物を広げる前に全部撮る**。スーツケースは浴室などに隠しておく。
- **立ち位置**：部屋の角か入口に立ち、**対角の奥の角**に向けて撮ると部屋が広く見える。すべての角から試して、一番よく見える場所を探す。
- **高さ**：**腰〜胸の高さ**で、スマホを**水平**に構える。壁や柱の縦の線がまっすぐになるようにする。下向きに撮ると部屋が歪む。
- **0.5x（超広角）**：狭い部屋や水回りで便利。ただし画面の端が歪むので、寝室では控えめに使う。
- **光**：昼間にカーテンを全開にして、室内の照明もすべて点ける。眺望と夜景は、日没前後の時間帯（マジックアワー）に別に撮る。

### 🎥 動画（ルームツアー）

- **ジンバル**はなくてもいい。スマホの手ブレ補正（アクションモードなど）を使って、**すり足でゆっくり**動けば十分。
- **動きの流れ**：ドアを開ける → ゆっくり前に進む → 左右に振る → 上下に振る → 細かいところに寄る。**1つの動きにつき1カット**にする。
- **1カットの長さ**：撮るときは3〜5秒、編集で1〜2秒に切るのが目安（実践者の経験則）。**最初の約3秒**で興味を引く。
- **編集**はCapCutが定番。カット、速度調整、自動字幕ができる。

### ♨️ 温泉の基礎

**泉質は10種類**（環境省の分類）：単純温泉・塩化物泉・炭酸水素塩泉・硫酸塩泉・二酸化炭素泉・含鉄泉・酸性泉・含よう素泉・硫黄泉・放射能泉。

- **単純温泉**は「含まれる成分が少ない」という意味で、**効能が低いという意味ではない**。
- 「美人の湯（炭酸水素塩泉）」「熱の湯（塩化物泉）」は**通称**で、正式な分類名ではない。
- **「〇〇に効く」と言い切らない**。効能の基準は2014年に改訂されていて、古い記事の情報は当てにならない。

**源泉かけ流し**には**法律上の定義がない**。一般的には、源泉を注ぎっぱなしにして、あふれたお湯を再利用しない方式のこと。

**加水**＝水を足す／**加温**＝温める／**循環**＝ろ過して再利用する／**消毒**＝塩素などを入れる。これらをしている施設は、そのことを**掲示する義務**がある（2005年から）。**脱衣所の掲示を見てから「かけ流し」と書く**。

**露天風呂付き客室**：お湯が**温泉ではなく普通のお湯**のこともある。投稿前に確認する。  
**貸切風呂**：予約制か、空いていれば使える方式かは宿によって違う。

### 🏯 旅館の基礎

会席と懐石

旅館の夕食は基本的に**「会席」**（お酒を楽しむ料理で、ご飯は最後に出る）。「懐石」は茶事の料理で、ご飯が最初に出る。

会席の流れ：先付 → 吸物 → お造り → 焼物 → 煮物 → 揚物・蒸物 → 酢の物 → ご飯・止椀・香の物 → 水菓子（デザート）

心付け（チップ）

**渡さなくていい**（料金にサービス料が含まれていることが多い）。特別なお願いをしたときは、1,000〜3,000円くらいをポチ袋に入れて渡すこともある。受け取りを断る宿も増えている。

時間

チェックインは**15時**、チェックアウトは**10〜11時**が多い。夕食は18〜20時くらいの開始時間を選ぶ方式が一般的。

浴衣

**右前**（自分から見て左の襟が上）で着る。**左前は死装束**なので、写真で間違えると目立つ。外出できるかどうかは宿によって違う。

入浴マナー

入る前にかけ湯をする。タオルを湯船に入れない。**浴室は原則撮影禁止**（人がいなくても施設の許可を取る）。

タトゥー

観光庁の2015年調査では、入浴を**断る施設が約56%**、許可が約31%、シールで隠すなどの条件付きが約13%。投稿では「**施設に要確認**」と書く。
